Logical Operators, Nesting and switch: Sample Programs

Files

1. logical_operators.cpp
   Demonstrates &&, || and ! in one access-control decision.

2. short_circuit_safe_division.cpp
   Demonstrates how && prevents division when the divisor is zero.

3. nested_if_access_control.cpp
   Demonstrates an if statement nested inside another if statement.

4. switch_menu_calculator.cpp
   Demonstrates a menu-driven calculator implemented with switch.

5. switch_grouped_cases.cpp
   Demonstrates several case labels sharing one block of code.

Compile a program with:

g++ -std=c++17 -Wall -Wextra -pedantic filename.cpp -o program
